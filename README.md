# Adobe Acrobat JavaScripts

A collection of JavaScript tools for Adobe Acrobat Pro.

## Scripts

### Bookmarks
- **Collapse-All-Bookmarks.js** – Collapses all bookmarks.
- **Fit-Height.js** – Sets pages under the selected bookmark section to Fit Height.

### Links
- **Create-Links.js** – Creates clickable links from text matching bookmark names.

## How to Use

1. Open the PDF in Adobe Acrobat Pro.
2. Open the JavaScript Console using `Ctrl + J`.
3. Paste the required script.
4. Run the script.

> Always save a backup copy of your PDF before running scripts that modify the document.
